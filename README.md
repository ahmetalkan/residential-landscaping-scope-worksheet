# Residential Landscaping Scope and Water-Efficiency Worksheet

A homeowner planning workbook for scoping yard projects, checking USDA hardiness zones, applying EPA WaterSense landscaping principles, calling 811 before digging, and comparing contractor bids.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — residential landscaping scope and planning worksheet: `https://ahmetalkan.github.io/residential-landscaping-scope-worksheet/`
- Subpage — utility locates, sun mapping, soil checks, and USDA hardiness zones: `https://ahmetalkan.github.io/residential-landscaping-scope-worksheet/site-grading-and-plant-zones.html`
- Subpage — water-efficient landscaping and xeriscaping basics: `https://ahmetalkan.github.io/residential-landscaping-scope-worksheet/xeriscaping-and-water-efficiency.html`
- Subpage — auditing nursery plant sizes, soil prep, and contractor quotes: `https://ahmetalkan.github.io/residential-landscaping-scope-worksheet/comparing-landscaping-estimates.html`

It cites public pages on [landscapingcostguide.com](https://landscapingcostguide.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
